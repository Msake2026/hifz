- **Amiri Quran** — The Amiri Quran Project Authors — https://github.com/aliftype/amiri — licence : `OFL-amiriquran.txt`
- **Cormorant Garamond** — The Cormorant Project Authors — https://github.com/CatharsisFonts/Cormorant — licence : `OFL-cormorantgaramond.txt`
- **Inter** — The Inter Project Authors — https://github.com/rsms/inter — licence : `OFL-inter.txt`
- **Noto Sans Arabic** — The Noto Project Authors — https://github.com/notofonts/arabic — licence : `OFL-notosansarabic.txt`

Les fichiers `.woff2` sont les sous-ensembles (arabe, latin, latin étendu) fournis par Google Fonts, sans modification. `fonts.css` déclare leur utilisation.
